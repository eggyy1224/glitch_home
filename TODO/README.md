# TODO 資料夾說明（展覽雜務用）

這個資料夾用來集中管理「圖像系譜學」展覽相關的待辦事項（非程式開發）。  
格式盡量簡單，方便創作者與策展方一起看。

## 檔案規劃（可依需要增減）

- `TODO/high_level.md`  
  - 目前整體進度、角色分工與大方向待辦。  
- 之後如有需要，可加：  
  - `TODO/works.md`：作品清單、版次、輸出尺寸等。  
  - `TODO/space.md`：各樓層配置、器材需求、施工重點。  
  - `TODO/design_and_promo.md`：主視覺、社群素材、印刷品、截稿日。  

## 使用原則

- 儘量使用條列式，標明「負責人」「截止日」「狀態」。  
- 不在這裡放太多長篇論述，長文請放在 `正式展覽相關文件/`。  
- 更新時可以直接編輯 markdown，不用維持嚴格的版本號，但請保留舊的關鍵資訊。
