# 正式展覽相關文件 / AGENTS.md

這個資料夾底下，主要是管理「展覽雜務」與「論述生產」相關的文件，不直接碰後端 / 前端程式碼。

## 本資料夾內檔案用途

- `20251226_discussion.md`  
  - 圖像系譜學、圖像信仰、圖像占卜等概念的長篇討論備份。  
  - 未來如需撰寫展牆文字、計畫書、press release，請優先閱讀並沿用裡面的語氣與比喻。
- `作品清單.*`、空間配置圖、場地相關 PDF / 圖面  
  - 與展覽實際製作、器材、空間規劃相關的檔案。  
  - 不要求任何 code style，但請保留原始檔名與版本，避免覆寫。

## 對論述相關 agent 的指引

- 語言：一律使用繁體中文。  
- 語氣：偏向創作者自身視角的口述風格，可以接近對話感，但要保持清楚、可被引用。  
- 優先維護的關鍵詞：  
  - 展名：**圖像系譜學**  
  - 核心概念：圖像系譜學、圖像信仰、圖像占卜、夜間群像合照、邪教感、放大器、時間被壓扁成一個瞬間。  
- 若要補理論（系譜學、媒介考古、群像肖像史、資料集政治），請以「輔助說明」為主，不要壓過創作者的語氣與具體母圖。

## 對「展覽雜務 / TODO」相關 agent 的指引

- 本資料夾的 TODO 以「人類看得懂、方便溝通」為優先，不必追求軟體專案那種嚴格 issue 流程。  
- 請避免幫創作者「決定」作品內容或空間配置，只能整理、提醒、補充格式與細節。  
- 可以幫忙做的事：  
  - 整理訊息、LINE / Mail 內容成為清楚的待辦與時程。  
  - 幫忙對齊「誰負責什麼」、「什麼東西要在什麼時間前給誰」。  
  - 協助生出樣板（例如：作品清單欄位、器材清冊欄位、宣傳文字模板）。

## 角色大方向（暫定版）

- 毛刺（空間方）  
  - 負責空間、統籌施工、燈光、設備協調、酷卡寄送、海報框架等。  
- 威辰（創作者）  
  - 負責作品本體、數位系統調整、展覽論述與影像／展場攝影。  
- 阿和（設計）  
  - 負責主視覺、社群圖、海報／酷卡設計與發包製作（含割字 / 卡典西德等），優先使用創作者提供之圖像素材。

## TODO 資料夾

- 在專案根目錄下會有一個 `TODO/` 資料夾，集中放展覽相關的待辦清單。  
- 未來如要新增待辦，請優先寫進 `TODO/` 底下的對應檔案。  
- 此 AGENTS 檔只管理「這個資料夾」與「TODO/」的風格與用途說明。
