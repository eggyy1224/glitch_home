# 後端架構概論（Backend Architecture Overview）

> 狀態: 與現況程式碼同步
> 最後更新: 2025-12-02

---

## 1. 技術棧、權限模式與啟動流程

- **Runtime**：Python 3.11+、FastAPI 0.115、Uvicorn 0.30。`app/main.py` 建立 app、開放 CORS（\*）、靜態掛載 `/generated_images`、`/generated_sounds`，若 `NIGHTWALK_ASSETS_DIR` 存在則另掛 `/nightwalk_assets`，並註冊所有 Router（含 scene/script/episode/clients）。
- **APP_MODE**：`STUDIO`（全功能）、`CONSOLE`（禁用影像生成／索引重建）、`DISPLAY`（唯讀，不做 metadata/asset 寫入、禁用分析 LLM）。`GET /api/runtime-caps` 會回傳目前模式與可用功能旗標，router 會以 `require_*_enabled` 驗證。
- **主要依賴**：Pillow/numpy（影像處理/拼貼）、google-genai（Gemini 生成/分析）、openai SDK（caption/embedding/TTS）、chromadb PersistentClient（向量索引）、httpx（ElevenLabs、OpenAI TTS）。
- **輸出**：新生成影像寫入 `settings.offspring_dir`，metadata 同名 JSON 存 `metadata/`；音效與 TTS 寫 `settings.generated_sounds_dir`，metadata 存 `metadata` 或 `metadata/naration/`。

## 3. 設定與環境變數（`config.Settings`）

- **APP_MODE 與旗標**：`APP_MODE` = `STUDIO` / `CONSOLE` / `DISPLAY`，分別決定 `enable_generation`、`enable_metadata_write`、`enable_asset_write`、`enable_index_rebuild`、`enable_analysis_llm`。唯讀模式會提醒哪些路徑仍可寫入。
- **金鑰/模型**：`GEMINI_API_KEY`、`ELEVENLABS_API_KEY`、`OPENAI_API_KEY`、`MODEL_NAME`(預設 `gemini-3-pro-image-preview`)、`OPENAI_EMBEDDING_MODEL`、`OPENAI_VISION_MODEL`、`OPENAI_TTS_MODEL/VOICE/FORMAT`。`GENAI_USE_VERTEX` + `VERTEX_PROJECT/LOCATION` 可切 Vertex。
- **路徑**：
  - `GENES_POOL_DIR` / `GENES_POOL_DIRS`：父圖來源（多資料夾皆可）。
  - `OFFSPRING_DIR`：生成影像存放 & `/generated_images` 靜態路由。
  - `METADATA_DIR`：共用 metadata 根目錄（包含 scenes/scripts/history）。
  - `NARATION_METADATA_DIR`：TTS metadata 儲存位置（預設 `metadata/naration`）。
  - `SCREENSHOT_DIR`：前端上傳截圖。
  - `GENERATED_SOUNDS_DIR`：音效/TTS 儲存 & `/generated_sounds` 靜態路由。
  - `NIGHTWALK_ASSETS_DIR`：若存在才掛載 `/nightwalk_assets`（預設指向 `夜遊 - 毛刺`）。
  - `VIDEO_ASSETS_DIR` / `VIDEO_ASSETS_PUBLIC_BASE`：iframe/video 控制時的影片資源路徑。
  - `CHROMA_DB_PATH`、`CAMERA_PRESETS_FILE`。
  - `IMAGE_SIZE` 控制送模型前的縮放；`ENABLE_IMAGE_EMBEDDING`、`google_*` 參數仍保留，實際嵌入目前由 OpenAI caption→embedding 提供。

## 4. API Router 速覽

- **storage_router**
  - `GET/PUT /api/iframe-config`：載入/覆寫 per-client 設定。
  - Snapshots：`POST /api/iframe-config/snapshot`（即時快照）、`GET /api/iframe-config/snapshots`、`GET/PUT/DELETE /api/iframe-config/snapshots/{client}/{name}`、`POST .../clone`、`POST /api/iframe-config/restore`。
  - `GET/PUT /api/collage-config`：載入/儲存拼貼設定（回傳 `source` 與 `updated_at`）。
  - `GET/POST/DELETE /api/camera-presets`：Kinship 視角 CRUD。
  - `POST /api/screenshots`：保存前端截圖，若帶 `request_id` 更新 queue 狀態。
- **generation_router**
  - `POST /api/generate/mix-two`：Gemini 混合（可自訂 parents/prompt/尺寸/格式/resize_mode）。
  - `GET /api/offspring-images`：列出 offspring 檔名 + URL。
- **indexing_router**
  - `POST /api/index/offspring|image|batch`：全量/單檔/批次索引。
  - `POST /api/search/text|image`：向量搜尋（可 `include_deprecated`）。
  - `POST /api/index/mark-deprecated`：將 `offspring_images/deprecated/**` 標記 metadata `deprecated=true`。
- **kinship_router**
  - `GET /api/kinship?img=&depth=`：回傳 parents/children/siblings/ancestors + lineage_graph。
  - `POST /api/kinship/rebuild`、`GET /api/kinship/stats`。
- **collage_router**
  - `POST /api/generate-collage-version`（multipart 或 image_names）、`GET /api/collage-version/{task_id}/progress`。
- **screenshot_router**
  - `POST /api/analyze-screenshot`（Gemini 2.5 Flash）、`POST /api/sound-effects`（ElevenLabs）、`POST /api/screenshot/bundle`（分析+音效）。
- **sound_router**
  - `GET /api/sound-files`(+metadata)/`GET /api/sound-files/{filename}`、`POST /api/sound-play`。
  - `POST /api/tts`（OpenAI TTS，auto_play 可推播）、`POST /api/speak-with-subtitle`（TTS+subtitle）。
- **realtime_router**
  - `GET/POST/DELETE /api/subtitles|/api/captions`（並透過 WS 推播）。
  - `GET /api/clients`、`POST /api/unlock-audio`、`POST /api/remote-click`、`POST /api/video-control`。
  - `POST /api/screenshots/request` → `GET /api/screenshots/{id}` → `POST /api/screenshots/{id}/fail`。
  - `WebSocket /ws/screenshots`：註冊 client 後推送 screenshot/sound/caption/subtitle/iframe/collage/remote click/video control/timeline_control。
- **clients_router**
  - `GET /api/clients/state`：列出所有 client 心跳/狀態/佇列數、當前/上一個執行項目、錯誤。
  - `GET /api/clients/queue?client=<id>[&status=&page=&limit=]`：依 client 分頁取得佇列，依 priority/eta 排序。
  - `POST /api/clients/queue`：新增 snapshot/timeline/episode 任務，可指定 `eta`（秒數或 ISO）、`priority`、`retries`、payload。
  - `POST /api/clients/queue/{id}/cancel|delay|move`：批次取消/延後/插隊（front/back 或直接覆寫 priority）。
- **timeline_router**
  - `GET /api/iframe-timelines`(+ client filter)、`GET /api/iframe-timelines/{id}`（`resolve=false` 可取原始 JSON）。
  - `POST /api/iframe-timelines`（新增）、`PUT /api/iframe-timelines/{id}`（覆寫）、`DELETE`、`POST .../{id}/clone`。
  - `POST /api/iframe-timelines/{id}/play`（廣播 timeline_control，可帶 startStep/loopOverride/commandId）、`POST /api/iframe-timelines/stop`。
- **episode_router**
  - Episode = 多 timeline track 編排：`GET /api/episodes`、`GET/PUT/DELETE /api/episodes/{id}`、`POST /api/episodes`、`POST /api/episodes/{id}/clone`、`POST /api/episodes/{id}/play`（可覆寫 target map / auto_play / force_iframe_mode / command_id_prefix）。

- **scene_router**
  - `GET /api/scenes` 列出、`GET /api/scenes/{id}` 讀取（可附 `version`，`resolve=false` 取原始 JSON）。
  - `POST /api/scenes` / `PUT /api/scenes/{id}`：新增/覆寫 Scene（驗證 snapshot/timeline 引用），可帶 `expected_version`，預設會 resolve 後回傳。
  - `POST /api/scenes/{id}/clone|publish|rollback`：複製、發布、回滾到指定版本；`/versions` 可查歷史。
  - `POST /api/scenes/{id}/play`：解析 snapshot config 並廣播到目標 client，支援 `allow_draft` 與 `audio_override`。
- **script_router**
  - `GET /api/scripts`、`GET /api/scripts/{id}`（可 `version`/`resolve=false`）。
  - `POST /api/scripts` / `PUT /api/scripts/{id}`：新增/覆寫 Script（驗證 scene/snapshot 引用），可 `expected_version`。
  - `POST /api/scripts/{id}/clone|publish|rollback|stop`：複製、發布、回滾、停止執行；`/versions` 查歷史。
  - `POST /api/scripts/{id}/play`：依序播放 scene 或 snapshot_pair，支援 `allow_draft` 與 `audio_override`。
  - Script/Scene 皆受 APP_MODE 的 metadata_write/asset_write 限制。

## 6. 主要服務（`backend/app/services/*`）

- **生成/輸出**
  - `gemini_image.py`：父圖解析（多資料夾/檔名/絕對路徑）、EXIF/縮放、呼叫 Gemini、輸出檔案與 metadata；支援 width/height/max_side + resize_mode。
  - `image_outputs.py`：縮放/fit/cover、寫檔（處理 JPEG 無 alpha）、記錄輸出尺寸。
  - `genes_pool.py`：genes_pool 多資料夾抽樣，或解析指定父圖。
- **搜尋/索引**
  - `vector_store.py`：OpenAI caption→`text-embedding-3-small` 建 Chroma；批次/單檔索引、fallback embed_image_as_text、mark deprecated。
  - `utils/embeddings.py`：OpenAI caption/embedding helper。
- **親緣**：`kinship_index.py` 掃描 offspring metadata 建 parents/children，查詢前會過濾不存在檔案並可自動重建。
  - **拼貼**：`collage_version.py` 記憶體 TaskManager（5 分鐘清理），切片/邊緣色比對/旋轉/抖動/seed，回傳 metadata + tile mapping（選擇性）。
- **配置 / Snapshot / Timeline / Episode / Scene / Script**
  - `iframe_config.py`：驗證 panel 檔名/URL、防 Path traversal；snapshot 讀寫 `snapshots/iframe_config/<client>/name.json`，支援 clone/metadata。
  - `collage_config.py`：回傳 config + `source`（default/global/client）與 owner_client_id。
  - `camera_presets.py`：JSON CRUD，附 `updated_at`。
  - `iframe_timeline.py`：解析 `timelines/iframe/*.json`，步驟支援 subtitle/caption/tts/remote_clicks/video_controls/unlock_audio_targets，resolve 時載入 snapshot config 並檢查 client。
  - `episode.py`：Episode 定義於 `metadata/episodes/*.json`，每 track 指向 timeline，可覆寫 target_client/autoPlay/loop/start_step/force_iframe_mode；播放時廣播多條 timeline_control（可帶 command_id_prefix 去重）。
  - `scene.py`：Scene 定義於 `metadata/scenes/*.json`，儲存 client→snapshot config 與可選音量設定，寫入 `history/scenes` 以便版本回滾，播放時會廣播 iframe_config。
  - `script.py`：Script 定義於 `metadata/scripts/*.json`，條目可以引用 scene 或左右螢幕 snapshot_pair，背景任務依序廣播 snapshot/scene 並套用音量，歷史寫入 `history/scripts`，支援停止與回滾。
- **即時與佇列**
  - `realtime_bus.py`：管理 WS 連線，依事件類型組 payload（可含 target_client_id），支援 timeline_control/remote_click/video_control/unlock_audio/client_state 等。
  - `client_queue.py`：每個 client 一條 in-memory queue + worker，支援 priority/eta/retries，執行 snapshot/timeline/episode；`/api/clients/queue` CRUD，執行/完成/失敗/取消時廣播 `client_state`（含 queue 前 20 筆）。
  - `screenshot_queue.py`：記憶體 queue，pending request 會透過 WS `screenshot_request` 推播；完成/失敗/音效就緒皆發事件，並具背景清理。
- **截圖/分析**
  - `screenshots.py`：驗證副檔名、命名 `scene_<ts>_<token>`、回傳相對/絕對路徑。
  - `image_analysis.py`：Gemini 2.5 Flash 場景分析（summary + segments），限制輸入尺寸避免超時。
  - `api/screenshot_helpers.py`：解析 `image_path`/`request_id` 找檔案、組 request metadata、推薦 sound prompt。
- **音訊/字幕**
  - `sound_effects.py`：ElevenLabs Text-to-Sound Effects（loop/duration/prompt_influence/model_id），寫 metadata（含 SHA256）。
  - `tts_openai.py` + `api/sound_helpers.py`：OpenAI `/v1/audio/speech`，安全檔名去重，instructions 造成 4xx 會自動重試移除；metadata 儲存於 `naration_metadata_dir`。
  - `sound_helpers.py`：列出音效（合併 naration/legacy metadata）、build URL、auto_play 時透過 WS 推播 sound_play。
  - `subtitles.py` / `captions.py`：`TimedTextManager` 支援 per-client、有效時間、自動到期清除。

## 7. 資料流程與狀態

### 7.1 截圖 queue
1) `/api/screenshots/request` 建立 request（可含 target client），`screenshot_queue` 推送 `screenshot_request`。  
2) 前端完成後 `POST /api/screenshots`（附 request_id/client_id），queue 標記完成並發 `screenshot_completed`，失敗則 `.../{id}/fail`。  
3) 分析/音效/bundle 若附 `request_id`，音效生成後以 `sound_effect_ready` 通知對應 client。

### 7.2 設定廣播
- `/api/iframe-config`、`/api/collage-config` 成功寫入即透過 WS 廣播，前端會鎖定遠端版本。
- 相機預設未廣播，Kinship 前端啟動時拉一次清單。

### 7.3 拼貼任務
- `generate_collage_version` 建立 in-memory 任務（`asyncio.create_task` + ThreadPool），進度寫入 TaskManager，前端輪詢 `/progress`。重啟後紀錄消失，輸出檔需自行搬運。

### 7.4 搜尋/索引
- `search_image` 接受任意路徑；若無嵌入則 runtime caption→embedding。批次索引支援 offset/batch_size；`mark_deprecated_images` 掃描 `offspring/deprecated/**` 寫入 metadata。

### 7.5 Timeline / Episode / 遠端控制
- Timeline 定義於 `metadata/timelines/iframe`，resolve 時載入 snapshot config 並整理步驟動作；`/api/iframe-timelines/{id}/play` 廣播 `timeline_control`（含 autoPlay/startStep/loopOverride/commandId）。`/api/iframe-timelines/stop` 可停止並釋放遠端控制。
- Episode 定義於 `metadata/episodes`，track 指向 timeline，可覆寫 client/loop/start_step/force_iframe_mode；`/play` 依 target map 發送多條 `timeline_control`，可附 command_id_prefix 避免前端去重。

### 7.6 音訊/字幕
- `/api/sound-play` 廣播檔名+URL，前端直接播放；`/api/tts` / `/api/speak-with-subtitle` 產生音檔、回傳 URL，`auto_play=true` 則推播 `sound_play`。後者會同步設定 subtitle 並經 WS 推播。

### 7.7 Client 狀態與播放佇列
- `/ws/screenshots` 的 hello/heartbeat 會更新 `ClientStateStore`（`last_heartbeat` + status），並即時推播 `client_state`。
- `/api/clients/state` 回傳所有 client 的狀態（online/busy/idle/offline、當前/上一個項目、錯誤列表、queue size）。
- `/api/clients/queue` 提供 per-client 佇列 CRUD，支援優先權、ETA、重試、批次取消/延後/插隊；worker 每個 client 單獨執行，完成/失敗/取消會清除佇列並推播最新狀態與前 20 筆佇列快照。
- 目前佇列為記憶體實作，重啟即清空；需要持久化時可接 Redis/SQLite（介面已隔離）。

### 7.8 Scene / Script 播放
- Scene 播放：解析 `metadata/scenes/{id}.json` 內的 client→snapshot config（含可選 audio_mix），廣播 iframe_config 到各 target client；未發布的 Scene 需開啟 `allow_draft`。
- Script 播放：依序執行條目，Scene 會轉交 `play_scene`，SnapshotPair 直接廣播 snapshot config 並可套用音量/靜音控制；支援背景任務取消（`/stop`）。

## 8. 既知限制與建議

- **揮發性狀態**：`ScreenshotRequestQueue`、`CollageTaskManager` 在記憶體中，重啟即遺失；需持久化時考慮 Redis/DB。
- **權限**：API 無認證/速率限制，公開部署前需加 auth/throttling。
- **觀測性**：部分服務仍以 print/簡易 log，建議改結構化 logging + 指標/告警。
- **大型檔案**：生成/拼貼輸出僅存在檔案系統，未提供 CDN/簽名 URL。
- **維運 UX**：timeline/episode 仍靠手動 JSON 編輯；可考慮 schema 驗證與後台 UI。
